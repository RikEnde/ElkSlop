# ROM sources (reference only)

Commented assembly for the two ROMs a stock Electron runs, kept as
documentation for reading alongside the emulator. **Nothing here is built**,
and nothing here is used by Gradle, the tests, or the emulator.

**The source files aren't in the repository**, because they have no licence.
To download them into this folder, run:

```sh
docs/rom-sources/fetch.sh
```

It fetches the exact versions listed below, checks every file's SHA-256, and,
if `64tass` is installed, generates `elk100.lst` and checks that it rebuilds the
original ROM. It needs `curl`, `tar` and `unzip`. The ROM images the emulator
loads are separate: `roms/` (see the main README).

Both are reconstructions by enthusiasts, not Acorn's original source files.

## `electron-os-1.00/`: Electron OS 1.00

A disassembly of the Electron's operating system ROM (`&C000-&FFFF`).

| | |
|---|---|
| Upstream | https://github.com/tom-seddon/electron_os_disassembly |
| Commit | `f07f7f9f284e61ad75264faef0aef5ebf1f52952` (2026-07-16) |
| Author | Tom Seddon; most comments come from J.G. Harston's MOS 1.00 disassembly |
| Status | Work in progress upstream: some labels are placeholders, some routines uncommented |
| License | None stated upstream |

Files:

- `elk100.lst`: **start here.** The assembler listing for OS 1.00: every line
  with its address, bytes, and comment, with the conditional code for other OS
  versions already resolved. Generated by `fetch.sh` with 64tass from the files
  below (we used 64tass 1.60.3243).
- `elk100.s65`, `src/*.s65`: the source, copied unchanged. `src/electron_os.s65`
  also covers Slogger's OS 3.00 through `version` conditionals; the `.binary`
  lines for OS 3.00 refer to upstream ROM images that are not copied here.
- `UPSTREAM-README.md`: the upstream README, with its credits.

Upstream's build (64tass with `MUST_MATCH=1`) reproduces the reference dump
exactly. We checked this on 2026-10-31: SHA-256
`efc902c006192c29198ada6125995e65eca29800486833b926c6eb9fb7578350`.

**Our `roms/os.rom` is this reference dump** (since 2026-11-01). We previously
used Elkulator's OS ROM, which differs in 48 bytes, all in the I/O area
`&FC00-&FEFF`. The real ROM hides Acorn's credits text there ("Thanks are due to
the following contributors..."), which programs normally can't read because the
I/O hardware overlays it. Elkulator's copy was evidently dumped by software on a
running Electron: the bytes at the readable ULA registers (`&FEx0`, `&FEx4`) and
at `&FCC0-&FCCF` hold I/O values instead of ROM text, which is why its credits
read "Chiis Turner", for example. Every address the CPU can actually see is
identical, so the emulator behaves the same with either.

## `basic-2/`: BBC BASIC II

`Basic2.src`: source for 6502 BBC BASIC II and III, as used in the Electron's
BASIC ROM (`&8000-&BFFF`, paged in as ROM 10/11).

| | |
|---|---|
| Upstream | https://mdfs.net/Software/BBCBasic/BBC/ (`Basic2.zip`) |
| Archive SHA-256 | `9dc2fcf6637bad57f46f146eacf5e0a1cd61d0d3a5af4a78eff0fd5e8eca410d` (fetched 2026-10-31) |
| Header | "BBC BASIC Copyright (C) 1982/1983 Acorn Computer and Roger Wilson. Source reconstruction and commentary Copyright (C) J.G.Harston" |
| License | None stated |

It is a BBC BASIC program that assembles itself under RISC OS with
`ARM BASIC 65`, and targets the BBC (which is also the Electron's BASIC), Atom,
System and C64. The archive's other files are RISC OS build scripts and are not
copied. Its BBC build script compares the result with the original BASIC 2.00
binary; we have not built it ourselves.
